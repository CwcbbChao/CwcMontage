# 时间轴编辑器实操指南

`CwcMontage` 内置了基于 Unity UIElements / IMGUI 打造的高性能蒙太奇可视化编辑器窗口。

通过菜单栏 `Window` -> `Cwcbb` -> `Montage Editor`，或在 `MontageSequenceSO` 资产的 Inspector 中点击 **Open Montage Editor** 即可打开。

---

## 界面布局概览

```
+-------------------------------------------------------------------+
|  [资产选择] [预览角色绑定]   [播放/暂停] [时间码: 0.45s / 1.20s]      |
+-------------------------------------------------------------------+
|  时间轴标尺 (Timeline Ruler)                                       |
+-------------------------------------------------------------------+
|  物理分段轨 (Physical Section Track): [Sec 0] [Sec 1] [Sec 2]     |
+-------------------------------------------------------------------+
|  主骨骼动画轨 (Animation Track)                                    |
+-------------------------------------------------------------------+
|  自定义表现轨 (Audio Track)      : [=== Play SFX ===]             |
|  自定义表现轨 (VFX Track)        :       [== Slash Light ==]       |
+-------------------------------------------------------------------+
|  属性检查器 (Action Inspector): 选中 Block 的参数细调               |
+-------------------------------------------------------------------+
```

---

## 核心交互操作

### 1. 时间指针洗牌采样 (Timeline Scrubbing)
- **拖拽播放指针**：按住鼠标左键在时间轴标尺区域左右拖拽，编辑器将实时以当前时间采样动画，驱动 Scene 视图中绑定的预览角色。
- **瞬态预览响应**：指针扫过 ActionBlock 时，编辑器将实时触发轻量级预览（例如播放对应音频片段、在视口挂点实例化粒子特效）。

### 2. 磁性吸附 (Timeline Snapping)
- 在编辑器右上角可开启 **Snap** 功能（快捷键支持），吸附单位支持：
  - **Frame 帧吸附**（按 30fps 或 60fps 帧对齐）。
  - **Section 吸附**（自动贴合分段切分点）。
  - **Block 边缘吸附**（自动贴合临近动作块的开始/结束边缘）。

### 3. 多轨道管理与动作块 (Tracks & ActionBlocks)
- **添加轨道**：点击轨道列表左上角的 `+ Track` 按钮，选择目标轨道类型（如 Audio、VFX、Spawn Prefab 或自定义派生轨道）。
- **新建动作块**：在轨道空白处双击，或右键选择 `Add Action Block`。
- **时长与范围调整**：
  - 拖拽 Block 左右两侧边缘调节时长（持续型动作块）。
  - 拖动 Block 整体移动发生时刻。
  - 选中 Block 后，右侧 Inspector 面板将展示该 Block 特有的字段（如 AudioClip 音量、VFX 旋转偏移、挂点骨骼等）。

---

## 视口预览角色绑定 (Preview Avatar)

在编辑器顶部的 **Preview Target** 栏位中：
1. 拖入场景中的角色实例或项目工程中的 Prefab。
2. 编辑器将在 Scene 视图中建立隔离的预览会话。
3. 当你调整动作块的 `Bone Socket`（例如挂接在 `RightHand` 或 `WeaponJoint`）时，视口将直接跟随骨骼层级实时呈现空间位置，无需反复运行游戏测试。
